SR-INFO – Smart Recycling Information System

SR-INFO is an Android application designed to provide simple and useful information about recyclable materials and proper recycling practices.

 Features

-  Search for recyclable objects
-  Get recycling information for different materials
-  Recycling Lab for exploring material composition and properties
-  EcoBuddy interactive assistant
-  Text-to-Speech support for information and guidance
-  Eco Game / Eco Challenge
-  Information stored using local JSON data
-  User-friendly Android interface

 Recycling Lab

The Recycling Lab provides a scientific examination of selected materials, including:

- Material composition
- Main components
- Molecular/particle-level information
- Physical properties
- Recycling information

Materials included in the application include:

- Paper
- Plastic Bottle
- Glass Bottle
- Battery
- Metal Can
- Plastic Bag

 Technologies Used

- Java
- XML
- Android Studio
- JSON
- Text-to-Speech (TTS)

 Platform:

Android Studio

Purpose

The project aims to make recycling information easier to understand and encourage users to learn about materials, their properties, and responsible recycling practices.
